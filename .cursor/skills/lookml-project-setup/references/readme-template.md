# LookML Linting (LAMS)

This project uses [LAMS (Look At Me Sideways)](https://looker-open-source.github.io/look-at-me-sideways/) to lint LookML for style and common issues. LAMS runs automatically in GitHub Actions on push and pull requests to `<default_branch>` (see `.github/workflows/lams.yml`). Rule configuration lives in `05_config/lams.yml`.

Run LAMS locally before committing and pushing to catch issues early:

```bash
npm install -g @looker/look-at-me-sideways@5 js-yaml
cd /path/to/<project_name>
lams --reporting=no --manifest=05_config/lams.yml --output=lines
```

A clean run produces no error lines. For more detail on rules, exemptions, and adding new checks, see `.cursor/skills/lookml-lams/SKILL.md`.

# Folder Structure

- **`00_dashboards`** — The home for all LookML dashboard files.
- **`01_base`** — Default LookML view files as generated by Looker. Do not edit these directly; use refinements in `02_standard` instead.
- **`02_standard`** — Refinement layers for base views. Extensions and derived table views also live here.
- **`03_logical`** — Explore files.
- **`04_models`** — Model files.
- **`05_config`** — Miscellaneous configuration (e.g. `value_formats.lkml`, `datagroups.lkml`, `manifest.lkml`, `lams.yml`).
- **`06_data_tests`** — LookML data test files.
```
